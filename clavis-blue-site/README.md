# Clavis 爽やかブルー版 静的サイト版

Figma Makeから書き出されたReact / TypeScript / Tailwind / Motion構成を、ブラウザでそのまま開ける静的サイトに整理したものです。

## ファイル構成

```text
clavis-static-site/
├── index.html          # ページ構造と文章
├── css/
│   └── style.css       # デザイン、レスポンシブ、CSSアニメーション
├── js/
│   └── main.js         # メニュー、スクロール演出、カウンター、フォーム
├── ATTRIBUTIONS.md     # 使用素材・ライセンス情報
└── README.md           # この説明
```

## 確認方法

`index.html` をブラウザで開くだけで表示できます。ローカルサーバーを使う場合は、このフォルダで次のどちらかを実行してください。

```bash
python3 -m http.server 8000
```

または

```bash
npx serve .
```

## JavaScriptで残している動き

- スクロール時のヘッダー背景切り替え
- スマートフォン用メニューの開閉
- ページ内リンクのスムーススクロール
- Intersection Observerによるスクロール表示演出
- 数値カウントアップ
- お問い合わせ送信後の完了表示
- 画像読み込み失敗時のフォールバック

## CSSで残している動き

- ファーストビューの見出し・説明・ボタンの登場
- 背景ラインのフェードと伸長
- スクロールアイコンの上下運動
- 技術名の無限マルキー
- カード・画像・ボタンのホバー演出
- `prefers-reduced-motion`への対応

## 注意点

- お問い合わせフォームは画面上の完了表示のみで、メール送信やサーバー保存は行いません。
- 実績画像とGoogle Fontsは外部URLを参照しています。完全オフライン化する場合は画像・フォントをダウンロードしてパスを差し替えてください。
- 会社名、住所、実績、数値は元データのサンプル内容をそのまま使用しています。


## カラーカスタマイズ

黒背景だったヘッダー、ヒーロー、Strength、Contact、フッターを爽やかなブルー系へ変更しています。配色は `css/style.css` 冒頭の `--blue`、`--blue-deep`、`--blue-footer` で調整できます。
